# شبیه سازی حرکات ساده چند object در فضای 3D در قالب انیمیشن 

این repository شامل مجموعه‌ای از شبیه‌سازی‌های گرافیکی با زبان پایتون است که هدف آن نمایش مفاهیم ریاضی و فیزیک از طریق انیمیشن، حرکت و میدان‌های برداری می‌باشد.
علاوه بر نمایش مسیر حرکت ، بردارهای هندسی مهم مثل مماس (Tangent)، نرمال (Normal) و بینرمال (Binormal) رو هم نشون داده شده.

#محتوای فایل‌ها:
- Multi_sphere_Dynamics.py  
  شبیه‌سازی حرکت چند کره در فضای سه‌بعدی و بررسی دینامیک سیستم‌های چندجسمی.

- Vector_Field.py  
  نمایش میدان‌های برداری با استفاده از پیکان‌های متحرک و رنگ‌بندی شدت و جهت بردارها.


#
مفاهیم ریاضی که استفاده شده:

مختصات سه‌بعدی (x,y,z) 
توابع مثلثاتی (sin, cos) 
نرمال‌سازی بردار (norm)
ضرب برداری (cross product)
گرادیان (grad)


# اهداف :
- نمایش گرافیکی ساختارهای ریاضی 
- ایجاد انیمیشن برای درک بهتر حرکت و دینامیک سیستم‌ها  
- تجسم میدان‌های برداری، گرادیان‌ها و تغییرات مختصاتی
